# Server Benchmarks

This directory will contain reproducible evaluation definitions and runners,
not personal recordings or downloaded models. No benchmark is implemented yet.

Evaluate capture-event coverage, retrieval recall at the episode level, small
object retrieval, provenance retrieval, and CPU processing throughput. Distinguish
capture failures from indexing and retrieval failures. Record dataset identity,
queries, expected episodes, model/preprocessing versions, and host configuration.

Keep large/private datasets and result artifacts outside the source tree. Public
fixtures must have explicit redistribution permission and provenance. Do not
publish OCR, thumbnails, paths, or result excerpts that reveal private material.
